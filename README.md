# 🐅 Tigrinho Simulador

Um simulador educacional do jogo Tigrinho, criado para fins de aprendizado e entretenimento. **Este é um jogo de simulação - não envolve dinheiro real.**

## 🎮 Funcionalidades

- ✨ Interface moderna e responsiva
- 🎯 Mecânica de jogo interativa com múltiplas combinações vencedoras
- 💰 Sistema de saldo fictício para simular apostas
- 🔊 Efeitos sonoros (pode ser desativado)
- 📊 Estatísticas em tempo real (taxa de vitória, maior ganho, etc)
- 🎨 Design atraente com gradientes e animações
- 📱 Totalmente responsivo para mobile e desktop

## 🚀 Como Começar

### Pré-requisitos
- Node.js 16+ instalado
- npm ou yarn

### Instalação

1. Clone o repositório
```bash
git clone https://github.com/yaagovieira/tigrinho-simulador.git
cd tigrinho-simulador
```

2. Instale as dependências
```bash
npm install
```

3. Execute o servidor de desenvolvimento
```bash
npm run dev
```

4. Abra seu navegador em `http://localhost:5173`

## 🛠️ Build para Produção

```bash
npm run build
```

Os arquivos otimizados estarão em `dist/`

## 📚 Tecnologias Utilizadas

- **React 18** - Biblioteca UI
- **TypeScript** - Tipagem segura
- **Tailwind CSS** - Estilização
- **Vite** - Build tool moderno
- **Lucide React** - Ícones

## 🎮 Como Jogar

1. **Defina o valor da aposta** usando o slider ou os botões rápidos
2. **Clique em GIRAR** para iniciar a rodada
3. **Ganhe combinações** de 3 símbolos iguais:
   - 🐅🐅🐅 = 5x sua aposta
   - 👑👑👑 = 6x sua aposta
   - 💎💎💎 = 4x sua aposta
   - 💰💰💰 = 3x sua aposta
   - 🎯🎯🎯 = 2.5x sua aposta
   - 🌟🌟🌟 = 2x sua aposta

4. **Monitore suas estatísticas** no painel inferior
